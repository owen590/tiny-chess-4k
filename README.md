A compact alpha-beta chess engine in 4 KB of Python — 0x88 board, iterative deepening to a fixed 3,000-node budget, quiescence search, transposition table, killer moves and MVV-LVA ordering, material + piece-square evaluation; practice Elo ~1190 on the house gauntlet (beats depth-2 and depth-3, draws the 100k-node engine).

## Run it

```sh
python3 main.py
```
